# Portfolio

Welcome to my professional portfolio! This repository contains the source code for my personal website, crafted with a focus on modern UI/UX, seamless animations, and clean design.

## ✨ Features

- **Modern Tech Stack**: Built natively with HTML, CSS, and JavaScript.
- **Morphic Animations**: Features smooth, hardware-accelerated 3D morphing and sliding scroll effects.
- **Fully Responsive**: Optimized for all devices and screen sizes.
- **Glassmorphism Design**: Beautiful translucent interfaces with dynamic, particle-based backgrounds.

## 🚀 Getting Started

Since this is a static site, no complex setup or local server is strictly required. 

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```
2. Open `index.html` directly in your browser.

## 📂 Project Structure

- `index.html` - The main structure of the page.
- `style.css` - Contains all styling, variables, glassmorphic utilities, and keyframe animations.
- `main.js` - Handles interactivity, scroll events, the particle canvas, and the morphic scroll effect.
